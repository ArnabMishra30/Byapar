# Screenshots to add

The guide references **15** screenshots. Drop each PNG in **this folder** using the
**exact filename** below, and it appears automatically when you recompile. Until
then, the guide shows a neat placeholder box in that spot, so it always builds.

## How to capture (please follow)
- Use the **real app** at your shop’s address, signed in as the **Shop Owner**.
- Crop away browser chrome (address bar, tabs) where practical.
- Keep text readable; use a desktop width so the sidebar is visible where relevant.
- **Never** show real passwords, OTPs, tokens, or real customer phone numbers —
  use demo/test data (e.g. the seeded demo shop).
- Save as **PNG**, roughly 1400–1800 px wide.
- Optional: add a small numbered circle over the button/field the caption talks
  about.
